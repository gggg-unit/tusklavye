# TuşKlavye 2.0

Türkçe Q klavyede on parmak yazmayı öğrenmek için masaüstü uygulaması. 15 ders, üç seviyede süreli testler ve kendi metninle pratik içerir. Hızını, doğruluğunu ve günlük çalışma süreni takip edebilirsin.

[Windows sürümünü indir](https://github.com/gggg-unit/tusklavye/releases/download/v2.0/TusKlavye-2.0-Windows.zip). ZIP dosyasını çıkarıp `TusKlavye.exe` dosyasını aç.

## Kaynaktan çalıştırma

```sh
python -m pip install -r requirements.txt
python main.py
```
